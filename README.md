# 胡不归

给想把日子过轻一点的人，一个从向往走到日常的起点。

- **寻找去处**：六种生活方式画像；关键词、类型与示例月开销筛选；本地收藏；最多三项横向对比；详情与实地核实清单。
- **谋生与预算**：三类谋生指南与行动步骤；六项生活开销；到手收入、存款、一次性费用与独立备用金；月度收支与余额可支撑时间；Markdown 导出。

- **界面**：自带山野插画，无外部图片或字体依赖；电脑、平板、手机布局；键盘操作、原生对话框、减少动画偏好与打印样式。

## 本地运行

不需要安装依赖或构建。使用 HTTP 服务打开，不能直接双击 HTML（浏览器的 ES module 限制）。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173`。有 Node.js 20+ 时可运行 `npm test`，无须 `npm install`。

## 数据与边界

`data.js` 的地区是**生活方式画像，不是具体城市、房源或招聘信息**。所有金额均为人为设置的演算示例，不是实时物价或收入保证；实际费用由用户询价后自行修改。后续增加具体城市时，应补上可核实来源、采集日期和季节差异，不能把示例直接改称调查数据。

预算口径：月开销为六项总和；备用金为月开销 × 预留月数；可用余额为 max(0，存款 − 一次性费用 − 备用金)；可支撑月数为可用余额 ÷ 月开销与收入的正缺口。收入已覆盖时不显示“无限续航”，准备金不足时优先显示缺口。未填入的费用不在演算内。

收藏、对比、预算、计划、手记、草稿和生活偏好使用 `localStorage` 键 `hubugui:v2`，仅当前浏览器、当前网站来源可用，不会自动跨设备同步。存储受限时会提示导出。用户清理浏览器数据前应备份；恢复会替换全部个人数据，不合并。备份格式仍为 v2；没有偏好字段的旧备份可正常恢复，偏好将初始化为空。导出的文件可能含个人记录，请自行保管。最多保存 100 篇手记，每篇正文最多 6,000 字，备份文件最大 2 MB。

公开社区使用仓库 `Leon-z7/hu-bu-gui` 的开放 Issues。网页只匿名读取最近 100 条开放议题中标题以 `[生活分享]` 开头的非 PR 条目；不读取完整历史、已关闭或其他格式的议题。发帖和回复均需访问 GitHub 并由用户登录后主动提交，网页不存储访问令牌。请求超时、限流或网络错误时有明确提示及直接访问入口。维护者可在 GitHub 编辑、关闭和管理公开内容。

## 维护位置

- `app.js`：页面与交互；`core.js`：可测试的预算、筛选与输入转义逻辑。
- `matcher.js`：偏好问卷与匹配结果交互；`matcher-core.js`：五题规则、回答校验与排序。环境、工作、城市联系、便利和节奏的单题最高分为 4、4、4、3、2，总分 17；开销上限先过滤，再按得分排序，同分保持画像原顺序。规则分数不是测评准确率或城市适合概率。
- `data.js`：生活方式、费用示例、谋生指南与试住清单。
- `styles.css`：色彩、排版和响应布局；`assets/`：自带矢量插画和站点图标。
- `tests/core.test.js`、`tests/matcher.test.js`：预算边界、组合筛选、手记输入，以及偏好校验、旧备份兼容、排序、预算筛选和输入不变性检查。

如未来需要站内账号、跨设备私密同步、房源与招聘发布，应单独建设身份、数据库、权限与内容管理；本版本不伪装这些服务已经存在。
